**Privacy & Networking**
- 🧅 **Tor / .onion** — The onion routing network that anonymises internet traffic by encrypting it and bouncing it through multiple volunteer-run relays worldwide. Used via Tor Browser for accessing .onion hidden services
- 🟣 **I2P (Invisible Internet Project)** — A separate anonymity network from Tor, designed for internal services ("eepsites") rather than accessing the clearnet. I run **i2pd** (the C++ implementation) and browse .i2p sites through Mullvad Browser configured with I2P's local HTTP proxy
- 🔒 **Mullvad DNS** — Using encrypted DNS-over-TLS for query privacy, and Mullvad Browser (a hardened Firefox fork by the Tor Project & Mullvad) as my privacy-focused browser
- 💰 **Monero (XMR)** — Privacy-focused cryptocurrency; using the Feather wallet connected through I2P's SOCKS5 proxy for anonymous transactions
